# CyberX Original Design System

## Source of truth

This design system was extracted from the original CyberX implementation in the legacy site files, especially:

- index.html
- awareness.html
- puzzle.html
- admin.html
- image/CYBERX-LOGO.png

The original website defines the visual identity that the product shell must follow.

## Design palette

Exact values recovered from the original implementation:

- bg: #0D1A2F
- bg2: #0a1525
- navy: #17364F
- cyan: #09D8C7
- red: #BD0927
- maroon: #500A1F
- text: #dfeff9
- text-muted: rgba(200, 224, 232, 0.72)
- border: rgba(9, 216, 199, 0.18)
- glow-cyan: 0 0 20px rgba(9,216,199,0.45), 0 0 40px rgba(9,216,199,0.15)
- glow-red: 0 0 20px rgba(189,9,39,0.45), 0 0 40px rgba(189,9,39,0.15)

These values are the only palette inputs to use for platform-wide UI consistency.

## Typography

Recovered type system:

- display: 'Orbitron', 'Segoe UI', sans-serif
- body: 'Rajdhani', 'Segoe UI', Arial, sans-serif
- mono: 'Share Tech Mono', 'SFMono-Regular', Consolas, monospace
- pixel: 'Press Start 2P', 'Orbitron', sans-serif

Original characteristics:

- uppercase technical labels
- wide letter spacing for UI labels and navigation
- cool-toned headline contrast
- strong cyber-tech display styling without a generic SaaS font stack

## Logo and brand treatment

The original CyberX logo asset is:

- image/CYBERX-LOGO.png

The original treatment uses:

- the logo image on the left side of the brand block
- CYBER as cyan or cool-toned text
- X as red text emphasis
- strong uppercase, condensed display treatment
- negligible chrome or generic rounded-square icon replacement

## Background language

The original site uses:

- dark navy body background
- layered radial gradients with cyan/red low-opacity glow
- subtle grid overlays
- clipped cards and panel blocks
- scanline-like low-opacity texture via layered backgrounds

The product pages should preserve this language rather than using flat gray or generic dashboard surfaces.

## Buttons and controls

The original buttons use:

- compact uppercase mono typography
- dark backgrounds with cyan or red accents
- clipped geometric corners
- low-opacity outlines and neon highlight accents
- strong border contrast, not full rounded SaaS pills

## Cards and surfaces

Original cards have:

- dark panel backgrounds
- thin cyan borders or red accent bars
- subtle shadows
- technical labels with uppercase forms
- border treatment derived from the legacy site, not glassy white-card UI

## Navigation principles

Original navigation uses:

- condensed uppercase navigation labels
- cyan-hover interactions with thin animated underline accents
- strong brand treatment on the left side
- consistent spacing and sticky header behavior
- active states using the original cyan accent palette

## Acceptance requirement

No new palette, green accent system, or generic SaaS UI layer may replace this design language.
