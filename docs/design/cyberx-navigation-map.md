# CyberX Navigation Map

## Public pages

- Home: /index.html
- Awareness: /awareness.html
- Puzzle Arena: /puzzle.html
- Learning: /learning.html
- Dashboard: /dashboard.html
- Pricing: /pricing.html
- Authentication: /auth.html
- Profile: /profile.html
- Leaderboard: /leaderboard.html
- Community: /community.html
- Resources: /resources.html
- AI Assistant: /assistant.html
- Admin: /admin.html (protected access)

## Homepage entry points

The homepage remains the primary information and discovery hub. It must link users into the public platform areas and product experiences directly from the main landing interface.

## Shared global navigation

The main header should remain consistent across pages and should expose product-level access to:

- Home
- Learning
- Puzzle Arena
- Dashboard
- Pricing
- Sign In
- Profile
- Leaderboard
- Community
- Resources
- AI Assistant

## Internal discovery pattern

- Learning links to dashboard, puzzle, resources, and profile
- Dashboard links to learning, puzzle, leaderboard, and community
- Leaderboard links to puzzle, dashboard, and community
- Community links to resources, learning, and profile
- Resources links to learning, community, and assistant
- AI Assistant links to learning, resources, and dashboard
- Awareness links back to home and the platform experience

## Footer links

The footer should point to key public destinations without inventing unsupported external services or fake accounts.

## Protected routes

The admin interface remains protected by its existing gate and authorization pattern. It should not be public-by-default.
